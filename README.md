# CrediLogic – CreditWise Loan Approval System

## 📌 Overview

CrediLogic is a Machine Learning-based Loan Approval Prediction System that predicts whether a loan application is likely to be approved based on applicant and financial information.

The project explores multiple supervised Machine Learning algorithms and compares their performance to identify the best model for loan approval prediction.

## 🎯 Objectives

- Predict loan approval based on applicant and financial data.
- Preprocess and analyze the dataset.
- Train multiple Machine Learning classification models.
- Compare model performance using evaluation metrics.
- Select the best-performing model for the final prediction system.

## 🤖 Machine Learning Models

The following classification algorithms were implemented and compared:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
